# 📖 Dicionário Português-Inglês em C++

Este é um projeto de um Dicionário interativo desenvolvido na disciplina de Algoritmos e Estruturas de Dados. O sistema utiliza o conceito de **Listas Encadeadas** para armazenar e gerenciar o vocabulário em tempo de execução.

## ⚙️ Funcionalidades

O programa roda diretamente no terminal e oferece o seguinte menu de operações:

* **Inserir Palavra:** Adiciona um novo par de palavras (Português -> Inglês) na lista.
* **Remover Palavra:** Busca e deleta um termo específico do dicionário.
* **Mostrar Dicionário:** Exibe todos os verbetes cadastrados e suas respectivas traduções.
* **Busca de Palavra:** Permite pesquisar um termo em português para encontrar sua tradução.
* **Traduzir Texto:** Uma funcionalidade avançada que lê uma frase inteira e traduz as palavras que constam no banco de dados do dicionário.

## 🛠️ Tecnologias Utilizadas
* C++
* Estruturas de Dados (Listas Dinâmicas Encadeadas / Ponteiros)
